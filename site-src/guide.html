Start here

What des-k does

Download the newest release

Windows already has virtual desktops. But one switch changes every screen at once. des-k gives each screen its own set of workspaces. You switch only the screen under your mouse.

Windows' own desktopsdes-k
  • Windows stay floating, as they normally are. des-k never tiles or moves them around.
  • It only hides and shows windows. Nothing is closed when you switch.
  • Your layout is saved, so a restart of des-k keeps every window on its workspace.

New here? Install des-k, then try your first switch. Both take a few minutes.

Words used here

Workspace

One set of windows on one screen. Each screen has 4 by default.

Hidden window

A window on a workspace you are not looking at. It still runs; you just cannot see it.

Indicator

The small card that shows for a moment after a switch. It tells you which workspace you are on.

Tray

The small icons at the right end of the taskbar, near the clock.

UAC prompt

The Windows box that asks "Do you want to allow this app to make changes?".

Rust

The programming language des-k is written in. You need it to build des-k.

Steps

How do I install it?

You need only Windows 11.

  1. Close any extra Windows desktops. des-k replaces them, and it can't see or bring back a window on another Windows desktop. Press Win+Tab, point at each extra desktop at the top, and click its X. Its windows move to the next desktop, so none of them close.
  2. Download the newest des-k-…-setup.exe from Releases and run it. To be sure it is really des-k's file, check the download first.
  3. Windows may say "Windows protected your PC". This is SmartScreen: the setup has no Windows code signature yet. Click More info, then Run anyway.
  4. Say Yes to the UAC prompt. When the des-k icon shows in the tray, des-k is running.

To update, click Check for updates in the tray menu. If a newer des-k is out, click the balloon or Install X.Y.Z in the menu. des-k downloads the new setup and runs it, but only when the publisher's signature checks out for that version (the same check as below). des-k stops, updates and comes back with your layout. If anything fails, a balloon says why and des-k carries on.

Keep to one Windows desktop while des-k runs. If des-k is already running, quit it from the tray before you press Win+Tab, since des-k takes that key over.

Why does it need admin? When an admin window (like Task Manager) is in front, Windows stops normal apps from hearing the keyboard. As admin, des-k hears its shortcuts everywhere.

Other ways to install

No admin rights (a work laptop, say)? Choose Install for me only when Setup asks. des-k goes to %LOCALAPPDATA%\Programs\des-k and still starts when you sign in. But without admin, its shortcuts stop while an admin window is in front, and it cannot move or close admin windows. Install X.Y.Z opens the release page instead, so you run the newer setup yourself.

From the zip. The release also has a zip with the same des-k.exe and install.ps1. Unzip it, open a terminal in that folder and run:

powershell -ExecutionPolicy Bypass -File install.ps1

From the code. You need Windows 11, Rust and Git.

  1. Open a normal terminal. Do not use "Run as administrator".
  2. Download the code and run the install script: 
    git clone https://github.com/CanaanGM/des-k
cd des-k
powershell -ExecutionPolicy Bypass -File install.ps1
  3. Say Yes to the UAC prompt, then look for the des-k icon in the tray.

The script does these steps for you:

  1. Build des-k
  2. Ask for admin once
  3. Copy to Program Files
  4. Start at every sign in
  5. Start it now

To update, get the new code with git pull and run the same install command again. Your workspaces are kept.

Steps

Your first switch

The first time des-k starts, a welcome screen opens. It helps you set up touchpad gestures and asks whether the Copilot key should work as Right Ctrl. You can change both later in Settings.

  1. Open two or three windows on one screen.
  2. Keep the mouse on that screen and press Win+Ctrl+Right. The windows go away, and the indicator shows workspace 2. Your other screens do not change.
  3. Open a window here. It lives on workspace 2.
  4. Press Win+Ctrl+Left. Your first windows come back, and the new one hides.

Nothing was closed. A hidden window keeps running; you just cannot see it. To find one, press Win+F. To see every workspace at once, press Win+Tab.

Right click the des-k icon in the tray for its menu: Shortcut hints, Settings, Open log, Check for updates, Pause des-k and Quit des-k.

Everyday use

Shortcuts

Every shortcut acts on the screen under your mouse. You can change any of them, or have them act on the focused window's screen instead.

Switch and jump

KeysWhat it does
Win+Ctrl+Left / RightGo to the previous or next workspace
Win+1 … Win+9Go straight to workspace N
Win+BackspaceGo back to the workspace this screen showed before. Press again to return, like Alt+Tab for workspaces.

Win+N on the workspace you are already on goes back too. After each switch, the indicator shows for a moment. It shows the workspace's number in its own color, its name if you gave it one, and a bar per workspace. With two or more screens, it also names the screen.

Send and pin

These act on the window in front.

KeysWhat it does
Win+Ctrl+Shift+Left / RightSend it to the previous or next workspace, and go with it
Win+Ctrl+Alt+Left / RightSend it there, but stay where you are

Win+Ctrl+UPin it: it stays on every workspace of its screen. Press again to unpin.
Win+Shift+Left / RightMove it to another screen (this one comes from Windows)

After a pin, every bar on the indicator lights up, because the window is on all of them. Sending a pinned window to a workspace unpins it.

Find and see

Forgot a shortcut? Tray → Shortcut hints lists every shortcut and gesture as you have them set.

Find any window

Press Win+F and type part of a window's name, its app or its workspace's name. Windows you used last come first. It searches every screen and every workspace.

Press Win+Tab. Every screen shows all its workspaces at the same time, with live pictures of the windows.

Steps

Switch with the touchpad

des-k reads three and four finger swipes and taps itself, so they work over every window, admin ones too. Out of the box, a four finger swipe left or right switches the workspace of the screen under the mouse. A four finger swipe up opens the overview.

Windows has its own gestures, and one swipe must never do two things. So des-k acts only while Windows' own three and four finger gestures are set to Nothing. The first time des-k starts, a welcome screen helps you:

  1. Set up in Windows Settings saves your current Windows values and opens Settings at Touchpad. Set the gestures there to Nothing.
  2. Choose my own does the same, and also opens the des-k settings page at Touchpad, where you change what each gesture does.

Open that screen again any time: settings page, Touchpad, Touchpad setup. Give gestures back to Windows there writes your saved values back. Quit gives them back too, from your next sign in.

Pause des-k

Sometimes you want plain Windows for a while: for a screen share, a game, or an app that does not like being hidden. Click Pause des-k in the tray menu.

  • Every hidden window comes back, on every screen.
  • Windows gets its own shortcuts back, like Win+Tab and Win+1.
  • Touchpad swipes do nothing until you resume.
  • Your Windows wallpaper shows instead of des-k's pictures.
  • The tray icon turns gray, and a new window opens where Windows puts it.

To go on, click Resume des-k in the tray menu. Each screen goes back to the workspace it showed, and the windows of other workspaces hide again.

Want a key for it? Set one at Pause des-k in Settings, Shortcuts (pause in settings.toml). It has none at first. While paused, that key is the only one des-k hears.

If des-k starts again while paused (after a reboot, say), it starts paused, and a balloon says so. Click the balloon to resume.

When a hidden window wants you

A window on a workspace you are not looking at leaves the taskbar and Alt+Tab, so each screen shows only what is on it. Admin windows, like Task Manager, still show in Alt+Tab. Store apps, like Calculator, keep their taskbar button, because Windows ignores des-k there. Clicking it takes you to the app's workspace.

When a hidden window flashes for attention (a new Slack message, a finished build), des-k shows a note on its screen, like "Slack misses you". That workspace keeps a small dot on the indicator and in the overview until you go there. Change the words at Popup words in Settings, Attention ([attention] text), where {{appname}} stands for the app's name. Turn the notes off with Show windows that want you ([attention] enabled).

When a hidden window comes to the front by itself, des-k switches its screen to that workspace. Turn that off with Follow a window in Settings, Workspaces (follow_activation).

Screens that come and go

When you unplug a screen or close the laptop lid, its windows move to the main display after 10 seconds (30 seconds just after a wake from sleep). Hidden windows keep their workspace number there, or go to the main display's last workspace when it has fewer. The windows you were looking at stay in view.

When you plug that screen in again, its windows go back after 2 seconds: same workspace, same place, same size. This also works after a sleep, a reboot or a power cut. A window you moved to another screen yourself stays where you put it. A note on the screen and a tray balloon say what moved.

des-k knows a screen by the monitor's own model and serial number, so another port or another dock is still the same screen. Settings lists the screens des-k waits for. Forget stops the wait for a screen you will not plug in again.

After a restart

After a restart of the PC, des-k puts reopened windows back on their workspaces, for the first 3 minutes after sign in. After that, windows open where you are.

Turn it off with Restore after restart in Settings, Restore ([restore] enabled), or change how long it runs with Restore runs for ([restore] minutes). Both wait for des-k's next start. To do this, des-k keeps your layout in state.txt.

Make it yours

Workspaces on each screen

Right click the des-k icon in the tray, then Settings. Every change saves at once. Each part below names the setting as the settings page shows it, with its line in settings.toml after it.

Each screen has 4 workspaces at first. In Settings, Workspaces, pick 2 to 9 with − and + (workspaces).

With two or more screens, each can have its own count: two on the laptop and six on the big screen, say. Under Workspaces per screen, each screen has a row of tiles. + adds one; point at the last tile, and its × removes it. That writes the screen's line in [workspaces_per_screen], by its id. A screen without its own line has workspaces.

workspaces = 4            # every screen without its own line

[workspaces_per_screen]
"internal" = 2            # the laptop panel

When a screen loses a workspace, its windows there move to the screen's new last workspace. Nothing closes.

Same number goes back (jump_back) makes Win+N on the workspace you are on go back to the one before.

Name your workspaces

A name tells you what a workspace holds, like "Mail" or "Code". In Settings, Workspaces, Names, type a name beside each number ([names] ws1 … ws9). The name shows next to the number on the indicator, in the overview, in the finder and in the tray menu. A workspace with no name just shows its number.

With two or more screens, pick a screen at the top of the card to give it its own names. Same as all screens on a row takes that screen's own name away again. You can also rename a screen there ("DELL U2720Q" becomes "Left"). To hide the screen's name on the indicator, turn off Show screen name in Settings, Indicator.

Steps

Change your shortcuts

In Settings, Shortcuts, click a key in the Key · click to change column, then press the keys you want. A shortcut that takes a Windows key says so on its row, like "Taken from Windows, where it opens Task View".

To give Win+Tab or Win+1 … 9 back to Windows, give des-k's action another key, and its row says the key is Windows' again. In settings.toml, an empty list turns a shortcut off: overview = [].

Keys act on

Shortcuts act on the screen under your mouse. To have them act on the screen of the window in front, set Keys act on in Settings, Workspaces to Focused window's screen (act_on = "focus"). That changes where switch, jump, back, the finder and the hints window act. Swipes always act on the screen under the pointer.

The Copilot key

On a new install, the Copilot key stays Windows'. To make it work as Right Ctrl, so Win+Ctrl shortcuts work with it, choose des-k at Copilot key as Right Ctrl in Settings, Shortcuts (copilot_as_right_ctrl = true). The welcome screen asks you this too.

Shortcut hints

Tray → Shortcut hints shows every shortcut and gesture as you have them set now. To open it with a key, set one at Open shortcut hints (hints). It has none at first.

Change how des-k looks

Where the indicator shows

In Settings, Indicator, click one of the 9 spots on the little screen picture: a corner, an edge or the center ([indicator] spot). Distance sets how far it stays from the edges (gap). Or choose Custom and drag it anywhere (x, y). With two or more screens, pick one in the Screen list to give it its own place. Same as all screens undoes that, and Show it there shows the real indicator on that screen.

The indicator's style

Style is a Card with the workspace number, or a plain row of Dots (style). Indicator stays and Indicator fades out set how long it shows and fades, in milliseconds (hold_ms, fade_ms). Workspace indicator turns it off (enabled).

Your colors

des-k's accent follows your Windows accent color and changes with it. In Settings, Colors, choose My own at Accent color to use your own instead ([colors] accent). Click its swatch and pick one of des-k's colors or any color on the wheel, or type one in the box, like 2E8B57. des-k mixes two neighbor shades from it for its headers and badges.

Each workspace can have its own color too (ws1 … ws9). Click its tile under Workspaces, a workspace in the Overview picture, or its swatch under Colors. A color you pick saves at once, and Esc puts the old one back.

You see your colors on the indicator, the finder, the overview and the tray menu. Reset puts des-k's color back. With Windows' high contrast on, des-k uses Windows' colors and ignores yours.

The overview and motion

Window names in overview shows titles on hover, always or never ([overview] labels). Overview animation opens it at once or with a quick fade (animation). Live overview updates it as windows open and close (live). Skip animations, in Settings, Motion, makes every des-k fade and move happen at once (fastest).

A picture for each workspace

Each workspace can show its own picture behind your desktop icons. Switch a screen, and only that screen's picture changes. des-k draws the picture itself, so your Windows wallpaper is never changed. A workspace with no picture shows your Windows wallpaper, and so does every screen after you quit des-k.

  1. In Settings, Workspaces, Wallpaper, click Open folder. Put your pictures there (.jpg, .png, .bmp or .gif).
  2. Click a workspace's row and pick a picture ([wallpaper] ws1 … ws9). It shows within a second or two.
  3. With two or more screens, pick a screen at the top of the card to give it its own pictures.

Slideshows. Put a few pictures in a folder inside the wallpapers folder and pick the folder, or tick several pictures in the menu. des-k shows them one after another. Interval sets the minutes per picture (interval), and each workspace can have its own pace. Shuffle picks a random order (shuffle).

A slideshow only moves while you can see it, so you come back to the picture you left.

Fit says how a picture fills the screen: fill (no bars), fit (bars on two sides), stretch or center (fit). Transition is an instant change or a short fade (transition). Dim pictures darkens them, so white icon labels stay readable on a bright picture (dim).

The overview shows each workspace's picture on its tile.

A picture that can't be shown (renamed, deleted or broken) shows your Windows wallpaper instead, and the Wallpaper card says why.

Open apps in their place

Tell des-k where an app belongs, and its new windows open there. Slack always on workspace 1 of the left screen, for example.

  1. Open the app. In Settings, Apps, click Add app and pick it from the apps open now. It starts with the workspace and screen it is on.
  2. Change its workspace or screen in its row. Any screen keeps it on the screen where it opens. In settings.toml, the line looks like "slack.exe" = { workspace = 1 }.

A new window of that app goes there the moment it opens. If that workspace is not showing, the window opens hidden, and a short note says where it went. Your screens never switch for it. Windows that were already open stay where they are.

des-k only matches apps. It never starts one. After a restart of the PC, a rule wins over des-k's restore: the app's windows go where the rule says.

Leave an app alone

Some apps break when hidden, or keep grabbing focus. To have des-k leave one alone, add it in Settings, Apps, then pick Leave alone in its Workspace menu. In settings.toml, that is "teams.exe" = "alone": an exe file name, or a Store app id.

  • des-k never hides its windows, so they stay in view on every workspace.
  • It never follows, places or restores them.
  • The finder and the overview leave them out. Reach them with Alt+Tab or the taskbar.
  • Send and pin do nothing to them, and a note says "des-k leaves Teams alone".

A window of that app that des-k had hidden comes back within a second.

Read the log

Tray → Open log. The log says what des-k did and why. Each line has the time and a level:

  • INFO: something done as intended.
  • WARN: a hiccup des-k carried on from.
  • ERROR: something you may notice, like a window that may stay hidden.

The first line names the des-k version and Windows build. At 5 MB the log starts fresh, and the old part moves to des-k.old.log, where the run before also lives. The log names windows by their app (chrome.exe), never by their title or folder, so it is safe to share.

Report a bug

Please open an issue on GitHub. Say what you did, what you expected, and what happened instead. Attach des-k.log (and des-k.old.log if the trouble was in the run before). Its first line names your des-k version and Windows build.

Found a security problem? Please do not open an issue. Follow SECURITY.md instead.

state.txt holds:

  • each screen: its model and serial number, its area, and which workspace it shows
  • each window des-k tracks: its app's file name (code.exe, never its folder), its window class, its place and size, its window handle and process id, and its title only while Restore is on (restore uses the title to tell two windows of one app apart)

While des-k runs, every tracked window is in there. Quit leaves only your screens and the windows waiting for an unplugged screen. To clear it, Quit from the tray, then delete state.txt. Deleting it while des-k runs does nothing: des-k writes it again at the next change.

None of it leaves your PC. The only thing des-k sends out is the update check you click: a request to github.com with your address and des-k's version, nothing else.

Steps

Stop or remove des-k

To stop it, click Quit des-k in the tray menu. Every hidden window comes back, so nothing is lost. des-k also forgets which window was on which workspace, and gives Windows its touchpad gestures back from your next sign in. To start it again, open des-k from the Start menu.

To remove it completely, uninstall des-k from Settings → Apps → Installed apps. The uninstaller quits des-k first, so every hidden window comes back.

If you installed with install.ps1 instead:

  1. Quit des-k from the tray.
  2. Open a terminal as administrator and run: 
    Unregister-ScheduledTask -TaskName des-k -Confirm:$false
Remove-Item -Recurse "$env:ProgramFiles\des-k"

Either way, your settings and log stay in %LOCALAPPDATA%\des-k. Delete that folder too if you want them gone.
