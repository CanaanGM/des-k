What des-k does

Windows already has virtual desktops. But one switch changes every screen at once. des-k gives each screen its own set of workspaces. You switch only the screen under your mouse.

Windows' own desktopsdes-k
  • Windows stay floating, as they normally are. des-k never tiles or moves them around.
  • It only hides and shows windows. Nothing is closed when you switch.
  • Your layout is saved, so a restart of des-k keeps every window on its workspace.

Words used here

Workspace

One set of windows on one screen. Each screen has 4 by default.

Hidden window

A window on a workspace you are not looking at. It still runs; you just cannot see it.

Tray

The small icons at the right end of the taskbar, near the clock.

UAC prompt

The Windows box that asks "Do you want to allow this app to make changes?".

Rust

The programming language des-k is written in. You need it to build des-k.

Steps

How do I install it?

The easy way needs nothing but Windows 11:

  1. Download the newest des-k-…-setup.exe from Releases and run it.
  2. des-k is not signed yet, so Windows may say "Windows protected your PC". Click More info, then Run anyway.
  3. Say Yes to the UAC prompt. When the des-k icon shows in the tray, des-k is running.

To update, run the newer setup the same way. Your workspaces are kept.

The release also has a zip with the same des-k.exe and install.ps1, if you would rather use a script. Unzip it, open a terminal in that folder and run:

powershell -ExecutionPolicy Bypass -File install.ps1

Or build it yourself

You build des-k on your own PC, then the same script installs it. You need three things:

  2. Download the code: 
    git clone https://github.com/CanaanGM/des-k
cd des-k
  3. Run the install script: 
    powershell -ExecutionPolicy Bypass -File install.ps1
  4. Say Yes to the UAC prompt.
  5. Look for the des-k icon in the tray. When you see it, des-k is running.

The script does these steps for you:

  1. Build des-k
  2. Ask for admin once
  3. Copy to Program Files
  4. Start at every sign in
  5. Start it now
Why does it need admin? When an admin window (like Task Manager) is in front, Windows stops normal apps from hearing the keyboard. As admin, des-k hears its shortcuts everywhere.

To update des-k later, get the new code with git pull and run the same install command again. Your workspaces are kept.

Shortcuts

Every shortcut works on the screen under your mouse.

KeysWhat it does

Win+1 … Win+9Go straight to workspace N
Win+Ctrl+Shift+Left / RightSend the window in front to the previous or next workspace, and go with it
Win+Ctrl+Alt+Left / RightSend it there, but stay where you are
Win+Shift+1 … 9Send the window in front to workspace N, and go with it
Win+Ctrl+1 … 9Send it to workspace N, but stay
Win+Shift+Left / RightMove a window to another screen (this one comes from Windows)
Win+FOpen the finder
Win+TabOpen the overview
Win+Ctrl+PPin the window in front: it stays on every workspace of its screen. Press again to unpin.

After each switch, a small row of dots shows for a moment. It tells you which workspace you are on. After a pin, every dot lights up, because the window is on all of them. Sending a pinned window to a workspace unpins it.

des-k takes two Windows shortcuts. Win+Tab no longer opens Task View. Win+1 … 9 no longer open taskbar apps. You can change this in the settings.

Find any window

Press Win+F and type part of a window's name or its app. Windows you used last come first. It searches every screen and every workspace.

Steps

Switch with the touchpad

des-k reads three and four finger swipes and taps itself, so they work over every window, admin ones too. Out of the box, a four finger swipe left or right switches the workspace of the screen under the mouse.

Windows has its own gestures, and one swipe must never do two things. So des-k acts only while Windows' own three and four finger gestures are set to Nothing. The first time des-k starts, a welcome screen helps you:

  1. Set up in Windows Settings saves your current Windows values and opens Settings at Touchpad. Set the gestures there to Nothing.
  2. Choose my own does the same, and also opens the des-k settings page at Touchpad, where you change what each gesture does.

Open that screen again any time: settings page, Touchpad, Touchpad setup. Give gestures back to Windows there writes your saved values back.

Reference

Settings

Right click the des-k icon in the tray, then Settings. The settings page can change everything below. The file behind it is %LOCALAPPDATA%\des-k\settings.toml. Each line has a comment that says what it does.

SettingDefaultAllowedWhat it changes
workspaces42 to 9Workspaces on every screen
follow_activationtruetrue, falseSwitch to a hidden window's workspace when it comes to the front
copilot_as_right_ctrltruetrue, falseThe Copilot key works as Right Ctrl
[shortcuts]see Shortcutslists like ["Win+F"]Every shortcut. An empty list turns one off.
[indicator] enabledtruetrue, falseThe row of dots after a switch
[indicator] hold_ms5500 to 5000How long the dots stay, in milliseconds
[indicator] fade_ms2000 to 2000How long the dots take to fade
[restore] enabledtruetrue, falseAfter a restart, put reopened windows back on their workspaces
[restore] minutes31 to 30How long after sign in to do that
[overview] animation"off""off", "fade"How the overview opens and closes: at once, or with a quick fade
[overview] labels"hover""hover", "always", "none"When the overview shows window titles
[overview] livetruetrue, falseThe overview updates as windows open and close

des-k checks the file once a second and uses a change at once. Only the [restore] settings wait for the next start.

A typo cannot break des-k. A bad value only sets that one setting back to its default. The log says which one.

Good to know

  • A hidden window leaves the taskbar and Alt+Tab, so each screen shows only what is on it. Admin windows, like Task Manager, still show in Alt+Tab.
  • When a hidden window comes to the front by itself, des-k switches its screen to that workspace.
  • After a restart of the PC, des-k puts reopened windows back where they were, for the first 3 minutes after sign in.
  • The tray icon menu has Settings, Open log and Quit.
  • des-k keeps the title, app and class of each window it tracks in state.txt, and its log names the windows it moves. Both stay in %LOCALAPPDATA%\des-k on this PC. Nothing leaves it.

Steps

Stop or remove des-k

To stop it, click Quit in the tray menu. Every hidden window comes back, so nothing is lost. des-k also forgets which window was on which workspace. To start it again, open des-k from the Start menu.

To remove it completely, uninstall des-k from Settings → Apps → Installed apps. The uninstaller quits des-k first, so every hidden window comes back.

If you installed with install.ps1 instead:

  1. Quit des-k from the tray.
  2. Open a terminal as administrator and run: 
    Unregister-ScheduledTask -TaskName des-k -Confirm:$false
Remove-Item -Recurse "$env:ProgramFiles\des-k"

Either way, your settings and log stay in %LOCALAPPDATA%\des-k. Delete that folder too if you want them gone.

For developers

Only one des-k runs at a time. Quit the installed one first, or the second one says des-k is already running and stops.

des-k uses a hidden part of Windows to hide windows. It works on Windows 11 25H2, but a big Windows update could change that. If it does, the tray shows a warning.
